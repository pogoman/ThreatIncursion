# Source map

One line per class in `src/threatinc/`, grouped by subsystem. Use it to find *which
file owns what* before you start; use an `Explore` subagent for the granular "where
exactly / what pattern / trace this logic" — that stays accurate against live code, this
map deliberately stays at the responsibility level so it doesn't go stale.

**Keep it current:** when you add a new class or change what an existing class is *for*,
update its one line here in the same change. Editing logic *inside* a class needs no
update. If the file list below ever drifts from `src/threatinc/*.java`, that's the signal
to reconcile it.

## Source map (`src/threatinc/`)

### Mod bootstrap & config
- `ThreatIncModPlugin.java` — mod entry point; registers the incursion manager and migrates old saves on load.
- `ThreatIncConfig.java` — central settings accessor, reading LunaLib live config or bundled JSON fallback.
- `LunaConfigBridge.java` — thin isolation wrapper around LunaLib's settings API, loaded only when LunaLib is present; also moves stored values still at an old default to a changed one, once per version.
- `ThreatNexCompat.java` — Nexerelin compatibility, soft (memory flag + reflection): flags besieged human colonies `$nex_npc_no_invade` and calls off Nexerelin invasions and AI ground battles already under way there (docs/nexerelin.md).
- `ThreatIncData.java` — persistent-data schema and accessors for all incursion state (stages, colonies, waves, garrisons, vitality).
- `ThreatDebugWar.java` — the Instant War debug switch: once per toggle-on, founds a connected network of mature hive systems (home chain plus footholds, a quota near the core), fills their garrisons and mobilises every faction, so a fresh save can test the war balance; also the Hive Floor Size lever (`pollFloor`), which grows every hive colony below a set size through the normal growth step, once per value.
- `ThreatSimDump.java` — what the offline simulator reads from a run: a `Clock: day N` log line once a game day, and behind `threatinc_debugSimDump` the star map once and the war's state (hives, human worlds, forward bases, stocks, stance) every 30 days as JSON in `saves/common` (`war-sim.md` 5).
- `rules/HiveRules.java`, `rules/PostureRules.java`, `rules/StanceRules.java`, `rules/SpreadRules.java`, `rules/StrikeRules.java` — the swarm's pure rules (package `threatinc.rules`: static functions on primitives, no game types), called by `ThreatColonyManager`, `ThreatColonyUpkeep`, `ThreatPosture`, `ThreatStance`, `ThreatFuel`, `ThreatReach` and `IncursionManager` and compiled as they stand into the offline simulator: fabrication and upkeep rates, the size table, size upkeep and growth rate; pressure decay, claim cap, releasable FP; stance shares; passage fuel, days away, the claim weight; the supplies gate on fleets away. The table of rule against call site is `war-sim-swarm.md` 2.

### Incursion core (spawning, colony lifecycle, siege engine)
- `IncursionManager.java` — the incursion's master clock: seeds infestations, dispatches waves, launches strikes/purges, drives all mod intel. Decides per world whether an NPC siege lands or works it from orbit (`razeWorlds`: a hive saturated only where its landing is beyond the marines held and it still produces, a colony razed where that is cheaper at vanilla base prices), and sizes a siege's landing, fleets and fuel (passage, ordnance, razing or saturation) on the bombardment plan.
- `ThreatColonyManager.java` — stateless colony logic: founding, growth/decline economy, garrison maintenance, siege/bombardment rules. Also runs the Threat's fabrication bank (`fabBank` / `fpBank` / `drawFP` / `chargeFP` / `creditFP`: forge output banked per colony, every fleet charged its FP) and the homecoming ledger (`bindToLedger` / `LedgerReturn` / `settleLedger`: surviving fleets credit their FP back on despawn); docs/hive-economy.md "Fabrication bank" (2026-09-29). The planner's idle-stock rules too (2026-10-01): a surplus fuel plant converted a month (`convertSurplus`) and the military tier bought with idle FP (`maintainMilitaryTier`, `militaryIdle`); docs/hive-reach-and-stock.md "Idle stock".
- `FabricationCore.java` — hive industry supplying heavy machinery from population; the colony's growth organ.
- `SwarmNexus.java` — hive's military industry; fabricates Defense Swarms/expeditions and anchors size-based ground defense (which bombardment unrest cuts through stability, as a colony's).
- `SwarmBastion.java` — the hive's military tier, two industries.csv rows on one class (2026-10-01): the Swarm Bastion and its upgrade Swarm Command, bought with idle FP at the Military Base / High Command price; standing, they double / triple the colony's reserve of Defense Swarms (`tier`, read by `ThreatColonyManager.garrisonReserve`) and add vanilla's Military Base / High Command ground-defence bonus, worn by disruption.
- `ThreatPosture.java` — the hive's defensive posture per system: reads pressure (attacks, staged enemy capacity, losses, hostiles, forward bases) every `postureDays`, sets each colony's wanted garrison (growth stops there), releases surplus to pressed siblings, waves and strikes, recycles idle surplus past upkeep break-even, and sets the expansion appetite `trySpread` reads.
- `ThreatStance.java` — the sector stance read each posture pass (PRESS / EXPAND / CONSOLIDATE) from strength against each rival in reach, weak known targets, the attrition and hive trend and how widely the hive is pressed: sets the strike stock staging colonies build, the strike pick's weights, expansion's share of the appetite, the spread's lean away from the strongest rival and, consolidating, feeding of THREATENED systems.
- `ThreatGroundDefenses.java` — machine-hive ground defense industry running on machinery/metals instead of vanilla marine logistics.
- `HiveVitalityCondition.java` — colony-screen tooltip surfacing the real hive vitality/decline numbers behind growth; under size upkeep, the share of its upkeep paid, any import cut and the growth pace or days to a size lost.
- `HiveBlockadeCondition.java` — "Blockaded" on a hive world: display only for the human blockade `ThreatBlockade.syncHive` sets (docs/ground-war-defenders.md "Blockade").

- `ThreatSwarmDefend.java` — the swarm's Defend stations: a strike fleet that landed or reinforced a Threat front stays over the world (ORBIT_AGGRESSIVE, no term), bombarding only while the front cannot hold (`ThreatGroundFronts.defendBombards`) and breaking up its own hulls for troops once orbit has nothing left to suppress (`defendFabricates`), home to its staging colony when the front is gone or the batteries have ground it below `defendMinStrength` - which a fabricating fleet is exempt from; also `holdOrbit`, which keeps any indefinite orbit station in place after a battle.
- `ThreatFabricationVisual.java` — the campaign-map animation for a fleet breaking itself up for the ground: glow trails falling INTO the planet (vanilla's own `Misc.addHitGlow`, the particles its bombardment burst uses, driven inward instead of scattered across the disc), a floating label and a danger ping, for a player in the system. Deliberately not the bombardment burst - this state is the one where the fleet has stopped bombarding.
- `ThreatPlanetaryShield.java` — replaces vanilla's Planetary Shield plugin (industries.csv): drops the x3 ground-defence bonus (`threatinc_shieldDefenseBonus`, 0 by default, and applied in proportion to condition when set) and writes the colony-screen tooltip for what the shield actually does here. Aliased to vanilla's class name in the save (`ThreatIncModPlugin.configureXStream`) so it carries no state and the mod stays removable.
- `ThreatShield.java` — the planetary shield as a military structure: it wears on the theatre's own disruption clock like any fortification, under the same diminishing returns, and what its condition buys is cover - `throughput` is the fraction of a bombardment day (and of a saturation day's fuel) that reaches the rest of the world, `soak` the full-weight share the shield takes itself. Sits in front of Useful Planetary Shield without overriding it.
- `ThreatRazing.java` — saturation's razing bar: fuel poured into the colony's top standing level, a level a size (satFuelSize4 razes a size 4, x3.2 a size up), layers a front holds counted as lost, the last level ending the colony; the dead stay dead, and a world being saturated does not grow (`saturated`). A hive has no bar (`razes` false, 2026-10-01): saturation presses it by the per-day rule alone, never a size off or a death, and a bar an older save left is cleared (`clearBar`).
- `ThreatAbstractBattle.java` — off-screen fights cost the defenders too (2026-10-01): after vanilla's autoresolve charges the attacker, every fleet and unspawned route defending the system (its factions read before the fight) loses min(0.75, half the attacker's strength over theirs); called from the siege and strike raid actions' `autoresolve`.
- `ThreatRazedCondition.java` — colony-screen condition on a human colony saturation has started razing (a hive has no bar): the level the bombs are on, how far it has gone, and the fuel that would end it.
- `ThreatSiegeMalus.java` — hidden structure carrying a human colony's siege state: each disrupted defence structure's multiplier restored in proportion to its condition, the districts-lost share of the ground defence, the stability / accessibility cost of districts held, and no growth while saturation falls; installed whenever a defence structure is suppressed, a front stands or the colony is being saturated.
- `ThreatGroundWarCondition.java` — colony-screen tooltip for a world being invaded: districts held and their cost, industries seized, defences suppressed, invader strength vs the garrison, next counter-attack, and - since the swarm came off armaments (2026-09-08) - what pressing is costing them, in place of the supply line they no longer have.
- `ThreatincMarketCMD.java` — overrides vanilla bombardment/military-menu rules: the player's bombardment of any world whose menu it runs (hives only with Nexerelin, which runs human colonies'), a day at a time under a shared once-a-day lock - tactical is a day of the siege slice, saturation the same on every building plus a colony's razing bar (a hive has none) - with the ships the guns take named; the ground-ops submenu (a landing is an act of war) and the hive defender rule for that menu (which swarm fleets count, what Engage targets, when raid/bombard close).
- `ThreatincAidCMD.java` — market dialog command: the station commander's hand-over of the player's cargo against an open request (rules.csv).
- `ThreatincNexCMD.java` — rules.csv conditions for Nexerelin: our military-menu overrides step aside on human colonies when Nexerelin is loaded, and its Invade is greyed on a colony the swarm besieges.
- `ThreatFortificationRaids.java` — the one raid on a war structure left: a hive's Fabrication Core, its days added in full and its marines lost growing with the tokens on it (tokens ^ coreRaidDepthLoss x the defence's share of the fight, read from the player's own raid strength). Every fortification, the Swarm Nexus and the planetary shield are unraidable.
- `ThreatGroundFronts.java` — persistent ground-siege mechanic: landing, pushing strata, counter-attacks, a front's wear by its advantage; with saturation (`ThreatRazing`) one of the two ways a human colony dies - a hive dies only to a ground victory. Owns the landing doctrine both expeditions call (`readyToLand` / `landingBlocked` / `landOrReinforce`), the bombardment day every besieger flies (`siegeSlice` / `saturationSlice` / `applyFleetLosses` / `abstractSiege`, `orbitSpent` / `bombardPlan` / `razePlan` / `saturationSpent` for when a commander stops bombarding - a day not worth the repair or the hulls, or the abort line - and `orbitPoints` for the fleets bombarding one world as one, `payOrdnance` for fuel, and `tickSupport` for Support and Defend sorties), the fabrication of ground troops from a Defend fleet's own hulls once bombardment has done what it can (`defendFabricates` / `fabricateNeed` / `fabricateCost` / `fabricateTroops`), the teardowns of a colony won or razed, and the `Theatre` (hive / colony) that answers everything depending on whose ground it is. Also `reliefNeed`, the marines an own colony under a Threat army still wants banked (what relief convoys are sized to, 2026-09-29).
- `ThreatPurgeFGI.java` — NPC/player siege expedition fleet-group: fights for the orbit first (no pass while Defense Swarms hold it, fleets at that world hunt them - `ThreatFleetOrders.siegeLeash` bounds the hunt and recalls strays), then the orbital duel (slices while the war-strata aren't worn out, spending no pass), then the landing - or a raid where it cannot land; or, on a world its faction works from orbit (`razes`), saturation until a colony is gone or a hive reaches the commander's stop (`razePass` / `razeAbstract`), paid from the fuel it carries (`razeFuel`; tactical `ordnance` for the rest). No slice where nothing can land; the landing fleet and every empty fleet in the system leave the group for an indefinite Defend over the front (`stayOnDefend` / `joinDefend`, `detach(fleet, false)`). Keeps the siege's hull ledger (`setLedger` / `settleLedger` / `pruneOne` / `settleUnplaced`): supplies settled against the fleets that really spawn, refunded per fleet on arrival home (2026-09-29); passage fuel refunded only for the return leg of lost hulls.
- `ThreatStrikeFGI.java` — Threat's own offensive fleet-group of swarm fleets, running the besiege-land-reinforce doctrine against inhabited worlds: fleets circling a colony suppress its fortifications a slice at a time while the batteries cost them ships, then land once the defences are worn out (saturation behind an off-by-default knob: the razing bar via `saturationPass`, the same rule the player and NPCs raze by; the frontier harassment strike flies one tactical slice a pass). The landing fleet detaches to a `ThreatSwarmDefend` station over the world; a fleet with nothing left to land joins one rather than slicing. Fleets spawn without `ALLOW_LONG_PURSUIT` and are held to the target by `ThreatFleetOrders.siegeLeash`. Books each strike on the staging colony's fabrication bank (the `ledger*` fields: what was paid, what the fleets really weigh, settled at spawn, homecoming credit if it ends unspawned; stillborn when broken in preparation; 2026-09-29). Packs its swarms into as few fleets as `maxShipsInAIFleet` allows (`pack` / `packs`).
- `ThreatFleetComposer.java` — builds every Threat fleet the mod spawns: vanilla sizes it, then the archetype picked for its job (strike, garrison, seeding, scout) re-spends the escorts' FP on its own hull mix and favoured variants (`data/config/threatinc_fleets.json`); `createScouts` builds scouting parties; the archetype is stamped as `$threatinc_archetype`.
- `ThreatOutposts.java` — the PLAYER's standalone orbital stations over uncolonised worlds (any; free after a ground victory) to block re-seeding by the swarm - NPC factions hold purged and conquered worlds with `ThreatFrontlines` forward bases instead, and old NPC outposts convert on load; each holds a stockpile and acts as a forward base and depot (convoys land, task forces hold its orbit); the player's keeps it in a storage-only market on the station (vanilla's abandoned-station recipe); inherited, stock and all, as the station industry of a colony its faction later founds there.
- `ThreatOutpostDialog.java` — the dialog when the player docks at their own outpost: open the storage (vanilla cargo screen), decommission, leave.
- `ThreatIncCampaignPlugin.java` — transient campaign plugin registered on load; picks `ThreatOutpostDialog` for the player's outpost stations and `ThreatNoticeClickDialog` for a clicked notice.
- `ThreatincOutpostCMD.java` — planet dialog command: "Build an outpost" over any uncolonised world in reach of a player military colony (rules.csv).

### Faction economy & war-effort reserves
- `ThreatWarState.java` — the master war-mode gate: tracks which factions are mobilised (NPCs after a Threat strike; the player only by their own Mobilise / Stand down buttons on the war board); excluded factions (`warExcludedFactions`, pirates by default) never mobilise.
- `ThreatReserves.java` — per-colony war reserve (marines/arms/fuel/supplies) that mobilised factions' operations draw from: a player colony's vanilla resource stockpile, an NPC colony's banked ledger; also `hasDepot`, the Waystation / Swarm Nexus gate a base needs; and since 2026-09-08 the garrison bookkeeping a siege spends - `armedMarines` (the call-up ramp over `marineArmingDays`), `marineXp`, and `spendDefendingMarines`.
- `ThreatMarineXP.java` — marine veterancy on vanilla's own shape: level = xp / headcount, ranks named by vanilla's `PersonnelRank` (Regular / Experienced / Veteran / Elite, for every pool including the swarm's), a hard fight teaches and a curbstomp teaches nothing, losses preserve the level and reinforcement dilutes it; holds the maths for a front's pool and a colony's, and bridges both to vanilla's `PlayerFleetPersonnelTracker` so a landing inherits the fleet's rank and writes back what it earned (`fleetLevel` / `fleetReturn` / `playerGroundSkillMult`). Hives have none of this - their strength is structural.
- `ThreatBases.java` — one handle over the two kinds of base a fleet ships from or home to: a colony (reserve with a floor) or an outpost (stockpile without one).
- `WarFootingDemand.java` — hidden industry declaring a mobilised colony's extra vanilla demand for war materiel.
- `WarFootingCondition.java` — colony-screen tooltip explaining the War Footing reserve and demand to the player.
- `ThreatBuildCost.java` — what a structure costs to build: its vanilla build cost in supplies and its vanilla build time, for the hive's planner and the factions' forward bases alike, and the structures a Seeding Swarm carries (`foundingKit`) or a faction's forward base stands up with (`linkKit`); also a structure's price in fleet points (`fleetPoints`, the hive's military tier) (docs/hive-economy.md).
- `ThreatColonyUpkeep.java` — size upkeep: a colony's supplies a month by size, the hive's feeding of it each poll (sustenance, then growth out of the stance's share), the growth rate the share paid gives, the import cut a blockade or dead port makes, and the spare supplies a trip may burn (docs/hive-garrison-and-upkeep.md "Size upkeep").
- `ThreatReach.java` — the hive's reach is its bill: a trip's passage and supplies away, the gate on what the colonies leave, days away for weighing targets per day, the faction a hive system would strike first, and the census's `Reach:` line (docs/hive-reach-and-stock.md "Reach is the bill"). Since 2026-10-01 the factions' too: `baseRangeLY` (how far a base's pooled stock pays its smallest siege flotilla's trip, what `IncursionManager.expeditionRangeLY` returns for an NPC base), `suppliesPerFP(faction)`, `tripSupplies` (docs/strategy-hunting-reach.md "The factions' reach and stance").
- `ThreatFactionStance.java` — each mobilised faction's own PRESS / EXPAND / CONSOLIDATE (2026-10-01): read weekly from how pressed it is, its exchange with the swarm, its force against the swarm facing it and the weakest hive system it could take and pay for now; gates link founding (`foundsLinks`), orders and gates sieges (`pressedFirst`, `pressingFirst`, `siegeAllowed`).
- `ThreatFuel.java` — the hive's fuel and supplies: two stocks its worlds fill with their plants' and forges' whole output (structures cost supplies) or a faction reserve's banking rate (not); fuel is drawn for the passage of every Threat fleet sent across hyperspace (strikes, raiders and scouts both ways, Seeding Swarms and reinforcements one way) at the factions' expedition rate, and a Seeding Swarm carries a forward base's supplies and fuel to found its colony; Threat fleets' supplies upkeep and, since 2026-10-01, the swarm's bombardment ordnance are drawn from it. Its trailing demand per stock - spent, and held for lack of it - is what the hive planner builds, spares and retires plants by (`runsDry`, `surplus`, `wantsSpare`, `surplusProducer`; docs/hive-reach-and-stock.md "Idle stock").
- `ThreatFrontlines.java` — frontline outposts: mobilised NPC factions found chains of small real markets toward hives none of their bases reach, grow and build them within vanilla import limits, keep standing garrisons at the front and call guards to rear links a seen strike is bound for, keep the chain's relay flags, dismantle purposeless links; also strike detection (`detectedBy`) (docs/frontlines.md).
- `FrontlineCondition.java` — the Frontline Outpost market condition: Forward Relay accessibility while the link is chain-connected to a colony.
- `ThreatConvoys.java` — physical logistics fleets shipping war materiel between a faction's colonies and its staging bases; also front runs, relief marines to an own world under Threat invasion, and outposts shipping a purged system's stock home. Loads past `maxShipsInAIFleet` split into parallel convoys. Owns `stockReachLY`, how far a market's stock reaches another (as far as its fuel pays a convoy's voyage; the donor rule of the planner, relief, and the siege and hunt pools), the haul a pool pays to take stock from afar (`haulRate` / `netOfHaul` / `payHaul`), and the relay plan (`relayPlan` / `relayHold`): a market its donors cannot cover names a relay depot that stocks from its own donors and ships onward, one convoy hop at a time.
- `ThreatReturns.java` — settles fleets sent home from any strategy-layer sortie, refunding cargo and drawn provisions; for NPC fleets the supplies drawn come back at the surviving health (`suppliesBack`: all of it under `ThreatUpkeep`, else the hull share `returnHullShare` 0.8), the player's keep the old rule (2026-09-29).
- `ThreatUpkeep.java` — NPC fleets out on the layer's orders burn their ships' vanilla supplies per month, paid from their base and the faction's markets in reach (docs/strategy-board-returns.md, "Fleet upkeep"); an off-screen siege that never spawned pays its allotment's the same way (`chargeAbstract`, 2026-10-01).
- `ThreatFleetOrders.java` — Guard/Support/Defend/Hunt sorties (Hunt replaced Intercept; old intercepts still run): the player's own navy on order, an NPC navy relieving its own invaded world or an ally's (`planRelief` / `sendRelief`, sized to the swarm overhead, merged into one Relief Force), and the player's aid task forces (flagged, on the capacity ledger, earning standing on arrival); Support (Escort until 2026-09-06, persisted kind still "escort") clears a besieged world's orbit so front runs can land and suppresses its defences while on station; a RAID (2026-10-01) is a Support flagged `raid` that the attack planner sends over a hive with no front (`dispatchRaid`; it leaves on the contest, the commander's stop or a third lost, `raidOver`, and may divert once to its fallback, `divertRaid`); Defend (2026-09-07, the same code with the kind a parameter: `dispatchOrbit` / `adoptOrbit`) holds the orbit and bombards only while the faction's front cannot hold, and is what an expedition's landing fleet takes by default (`adoptLandingDefend`, no term). A player guard over an own colony is staging: it stays until recalled, its points are the host's, sorties fold it in (`fold`) and the same hulls go back on station when they are home (`restation`). Support takes over the nearest fleet already out (`nearestReassignable` / `takeOver` / `adoptSupport`). Also owns the SIEGE LEASH (2026-09-07, `siegeLeash` / `nearestWorld`), the one place that decides where an expedition fleet of either theatre may go: aggression only inside `siegeHuntRange` of a contested world, vanilla's `$doNotGetSidetracked` blinkers everywhere else, and a recall past `siegeLeashRange` or out of the system.
- `ThreatCoalition.java` — allied factions answering a siege call with hunting task forces, and helping each other's colonies (guards, convoys) by standing; the player can be helped.
- `ThreatAidCapacity.java` — the capacity ledger: fleet points a player colony can have at sea (vanilla fleet-size stat x aidBaseFP), held by every fleet it launches until it is home or rebuilt; a colony's free points include the task forces staged there (guards over it), which a combat sortie folds in. Nothing sails over-extended.
- `ThreatAid.java` — player aid from the war board: source auto-pick, quotes and dispatch of Defend/Aid/Strike (paid by the source colony's reserve and capacity, no credits), standing on arrival, crediting deliveries to open requests.
- `ThreatBlockade.java` — "Blockaded" condition: Threat warships over a human colony cost it accessibility, vanilla's League blockade per colony; and the other way round, human warships over a hive world cut its imports and exports under size upkeep (`syncHive`, `hiveCut`).
- `ThreatAidRequests.java` — mobilised NPC colonies' needs (outmatched by a strike; exhausted or standing shortages) and the slow tick that posts requests for help.
- `ThreatRaiders.java` — hive garrison swarms detached to hunt enemy supply convoys (guerre de course).
- `ThreatScouts.java` — the fog of war on hives: NPC scouting parties that find hive systems (leads from strikes, routine sweeps), the shared discovered list every faction acts on, and `sectorKnows`, the gate on NPC war efforts. Also `recon`, a party the attack planner sends to look again at a found system (its arrival writes a SCOUT report).
- `ThreatIntel.java` — the fog of war on the swarm's strength (2026-10-01): each mobilised faction's and the player's REPORT of each Threat system (swarm FP within the contest radius of each hive world, the rest loose, the day and how seen), made only by eyes (a fleet, colony, army or route there), radar (forward bases, military worlds, the player's outposts within `radarRangeLY`, two figures) or a scout; partners pool reports, the player reads Cooperative factions'. Readers ask `report` / `worldFP` / `trust` (0.5 ^ (age / `intelHalfLifeDays`)) instead of the live garrisons; with `intelFogOfWar` off they get the live picture. `figure` / `when` are the board's text.
- `ThreatAttackPlanner.java` — the NPC attack planner (2026-10-01): per mobilised faction, weekly and on news, from its reports: recon where the picture is old, sieges easiest first until the chance at least one in flight lands (1 - product of (1 - trust at arrival)) reaches `planConfidence`, then raids ranked by cost per day down x trust, sized by the guns and twice the reported swarms, held to arrive with a siege in the same system. Replaces the monthly siege pass's target picking (`IncursionManager.tryPurgeBombardments` stands aside while `attackPlanner` is on) and launches through `IncursionManager.launchPlanned`, `ThreatFleetOrders.dispatchRaid` and `ThreatScouts.recon`.
- `ThreatWarCouncil.java` — the NPC war council (2026-10-01): per mobilised NPC faction, a monthly `Picture` of the swarm's known clusters from worlds, sizes, tiers and spread (never swarm FP) and a strength band; a strategy (Hold, Starve, Roll back, Decapitate) drawn by weighted chance every `councilReviewDays` (personality x learned odds, temperature); sets the faction stance (`ThreatFactionStance.set`) and hands the focus to `ThreatPlays`. While `warCouncil` is on, the attack planner and the monthly siege pass stand aside. docs/war-council.md.
- `ThreatPlays.java` — the council's plays (2026-10-01): RECON, HAMMER, STARVE, FEINT, BOMBERS and JOINT, each with phases on its own clock, sequencing sieges (`launchSiegeExpedition` with a `playId`), held hunting forces (`ThreatSoftening.sendPlay`), raids, scouts and play staging (`ThreatConvoys.stageForPlay`). Sized by shares of the means, not the swarm's FP; judged by damage done, which feeds the council's learning. docs/war-council.md section 16.
- `ThreatMapFog.java` — the fog of war on vanilla's own screens: while a core tab is open (game paused, economy still), every Threat market in a system the player has not found is veiled - hidden, condition-only at its pre-hive survey level, planet neutral - so the galaxy map, system view and intel lists show an ordinary planet; lifted the frame the tab closes. The mod reads markets through `hidden` / `conditionOnly`, which see through it. Not `setHidden` for good: a hidden market takes no imports.
- `ThreatScoutRoute.java` — the route walker both scouting sides share (each holds one as `ROUTE`, hooks for what its party does at a stop): sent stop to stop, look on entry, stay scoutStayDays, skip stops learned of meanwhile or not reached in scoutLegMaxDays, report home or fade; `Party` is the persisted record each side's `Scout` extends, and `nearestFirst` / `taken` order a new route and keep two parties off the same system.
- `ThreatMissionFilter.java` — filtering subclasses of vanilla's generic mission creators (analyze, survey, procurement) so a hive market never posts one; `install` reshapes the manager's list each load (unwraps the retired wrapper, drops the duplicates it let accrue, swaps plain vanilla creators for the subclasses). Subclasses, not wrappers, because vanilla's `hasMissionCreator` is an `isInstance` test.
- `ThreatSwarmScouts.java` — the swarm's side of the fog: Scouting Swarms chart inhabited systems in fuel reach, and `swarmKnows` gates which worlds a strike may target.
- `ThreatSwarmIntel.java` — the swarm's fog of war on human forces (2026-10-01): contacts (attacks it saw, bound for which hive system) and places (staging, forward guards, base reach, a target's defence) made by its eyes (a hive, Threat fleet, strike route or Threat front in the system), radar (Bastion and Command worlds within `swarmRadarRangeLY`) and Scouting Swarms, aged by `intelHalfLifeDays`; posture, the strike gate, the spread and raiders read it when `swarmFogOfWar` is on (docs/threat-fog.md).
- `ThreatNotice.java` — every one-off notification the mod posts: title (colour-coded good/bad/neutral), then bullet lines with faction names in faction colour, markets in owner colour, figures highlighted; replaced MessageIntel and `announceAlways`. `ThreatColonyManager.announce(ThreatNotice)` is the debug-only route. Clicked, a notice opens the war board on its faction's tab (crest faction, else first faction/market named, else the Threat tab); no click while the board is hidden. `ThreatNotice.Reason` is a refusal's facts, one per line, shown as the notice's bullets and as a button's tooltip text (`ThreatAid.Quote.reason`, `canAid`, `orbitRefusal`, `pushRefusal`).
- `ThreatOmens.java` — foreboding messages until anyone finds a hive: static near an unfound hive, rumours of new seeds, swarm scouts and unseen strikes, one "ships going missing" line at phase 2 (docs/omens.md).
- `ThreatAlarm.java` — escalation/grudge tracking that retargets strikes at aggressors (it no longer speeds hive fabrication, 2026-09-29).

### Ground war support / mission design
- `ThreatMissionIntel.java` — dynamic defense-board contracts scoring and offering strikes against specific hive infrastructure links.
- `ThreatAidMissionIntel.java` — a faction's request for help at a colony as a vanilla mission: Defend (a window; fails if a strike lands; needs a player asset present) or Deliver N of a commodity (running total from convoys and hand-overs).
- `ThreatSwarmBountyIntel.java` — a swarm bounty: an NPC base whose siege a hive system's Defense Swarms outweigh pays per Threat ship the player destroys there, by hull size, for `swarmBountyDays` - or, posted by an NPC colony whose orbit the swarm holds over a landed Threat army, on its own system until the army is gone (`postRelief`) (vanilla's system bounty; `Kills` hears the player's battles, `HunterPay` rides the player's hunting fleets).
- `ThreatSoftening.java` — NPC hunting forces: bases with no hive of their own to siege pool a force (Hunt orders sharing a `Force`) against a bountied hive system's Defense Swarms; it musters outside the system, goes in together against the world the siege's orbit gate reads (the strongest garrison among the siege's worlds), paid in fuel and supplies. Also runs the player's single-fleet hunts (weakest first).

### Custom intel UI / war board
- `ThreatWarBoard.java` — the custom-drawn "The Abyssal War" war board (large description of `ThreatIncursionIntel`): ledger (with the Activity crests), the selected system's ground-fronts table (also drawn by the faction view; row buttons Push / Dig in / Support / Pull out / Supply), colony cards. The mod's bespoke war-board UI — re-read before patching (two sessions have edited it concurrently).
- `ThreatFactionView.java` — the war board's per-faction drill-down view (colonies, reserves, fleets, order buttons) shown when a mobilised faction is selected.
- `ThreatIncursionIntel.java` — the permanent sector-wide intel entry hosting the war board and routing its button/click events.
- `ThreatColonyScreenDialog.java` — opens vanilla's own colony info screen for a hive world from the war board, no custom UI.
- `ThreatNoticeClickDialog.java` — invisible dialog behind a clicked `ThreatNotice`: sets the board's faction tab and opens the Intel screen on it (vanilla's INTEL_TAB click cannot select an intel that is not in the manager).

### Other intel screens
- `SeedingSwarmIntel.java` — transit tracker for an in-flight colonization wave, from launch to planetfall or destruction.
- `InfestedSystemIntel.java` — per-system infestation marker (hidden; a map anchor with a status panel and the debug purge button; the purge-commission UI was removed 2026-09-05).
- `ThreatResponseIntel.java` — tracks a real NPC task force dispatched to retaliate against the colony that struck it.
- `ThreatSiegeReportIntel.java` — after-action sitrep summarizing what a siege expedition did to each target colony.
- `ThreatBountyIntel.java` — retired legacy intel class kept only so pre-rework saves deserialize and self-retire.
