Where it lives
Give the existing Threat Incursion major-event intel hasLargeDescription() = true and build the board in createLargeDescription. It already carries INTEL_MAJOR_EVENT, so it sits beside colony crises in the list, and the per-system InfestedSystemIntel entries stay as the map markers and the "show on map" targets.
Selection state (which row is expanded) lives on the intel object; a row click calls ui.updateUIForItem(this) to redraw - the same pattern the commission button uses.
